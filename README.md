# Pixel Fighters — 2D-файтинг на Godot

Файтинг на Godot 4.7: 6 персонажей, 2 арены, бои против бота или вдвоём на одной клавиатуре, best-of-3, настройка клавиш, автотесты.

## Как запустить (скачав этот репозиторий)

1. Установите **Godot 4.7** (или новее) с [godotengine.org/download](https://godotengine.org/download) — обычная версия (не .NET).
2. Откройте Godot, в окне менеджера проектов нажмите **«Импорт»**, укажите папку `PixelFighters` (файл `project.godot`).
3. Дождитесь импорта ассетов (первый запуск чуть дольше).
4. Запуск игры — клавиша **F5** (или кнопка Play в редакторе).

## Экспорт

В `export_presets.cfg` есть пресеты Linux, Windows и macOS (Universal: arm64 + x86_64, один бинарник на оба Mac).
Экспорт: редактор → Project → Export, нужен установленный пакет экспортных шаблонов той же версии Godot (Editor Settings → Export Templates → Download).
macOS-билд не подписан: на Mac запускайте правым кликом → «Open» (один раз) или `xattr -d com.apple.quarantine PixelFighters.app`.

## Главное меню

- Выбор персонажа — клик по карточке.
- «Арена»: Додзё / Пещера (разные границы, платформы, декор).
- «Режим»: против бота (3 сложности) или 2 игрока на одной клавиатуре.
- «УПРАВЛЕНИЕ»: клик по клавише → «нажмите…» → живое нажатие назначает клавишу, Esc отменяет; есть сброс по умолчанию, настройки сохраняются.
- «НАЧАТЬ БОЙ».

## Управление

- **Игрок 1 (по умолчанию)**: A/D — движение, W — прыжок, S — присед, J — быстрый удар, K — сильный, L — способность, Shift — рывок.
- **Игрок 2 (по умолчанию)**: стрелки, 1 — быстрый, 2 — сильный, 3 — способность, Ctrl — рывок.
- Клавиши полностью переназначаются в «УПРАВЛЕНИИ».
- **Авто-блок**: бездействие = защитная стойка, входящий урон ~15%; при защите — анимация блока.
- **Присед**: низкая стойка, высокие удары пролетают над головой; удар из приседа — подкат по ногам.
- **Удары в воздухе** превращаются в прыжковые удары; у LUNA двойной прыжок.
- **Потеря равновесия**: сильный удар, полученный в прыжке/атаке/рывке, сбивает персонажа (анимация вставания).
- Комбо: быстрый → быстрый → сильный (отменяется при попадании).
- Пауза в бою — **Esc**; после боя: Enter — меню, R — заново.

## Раунды

Best-of-3: 2 раунда = победа в матче. Раунд — 99 секунд, по таймеру побеждает тот, у кого больше HP. Нокаут — K.O. с замедлением и тряской.

## Персонажи

- **VEX (striker)** — HP 100, быстрый; способность: усиленный удар с рывком.
- **TITAN (bruiser)** — HP 140, тяжёлый; способность: землетрясение с ударной волной.
- **LUNA (acrobat)** — HP 80, двойной прыжок; способность: удар в воздухе.
- **MAGNA (mage)** — HP 90; способность: огненный снаряд (запуск на земле).
- **NOVA (shadow)** — HP 75, самый быстрый; способность: стремительный контр-удар.
- **RICO (gunner)** — HP 85; способность: скоростной снаряд.

## Структура

- `scripts/CharData.gd` — данные персонажей (HP, скорость, удары, анимации).
- `scripts/ArenaData.gd` — арены (границы, платформы, декор) — новая арена = одна запись.
- `scripts/RoundRules.gd` — правила раунда/матча (чистые функции).
- `scripts/BotAI.gd` — ИИ бота по сложности.
- `scripts/Fighter.gd` — боевая логика бойца (состояния, хитбоксы).
- `scripts/Projectile.gd` — снаряды.
- `scripts/Fight.gd` — матч: N бойцов (2+), HUD, раунды, ввод.
- `scripts/MainMenu.gd` — меню и настройки клавиш.
- `scripts/GameState.gd` — автозагрузка: выбранные режим, арена, персонажи, клавиши (`user://controls.cfg`).
- `assets/Anim/` — спрайт-листы (128×128 на кадр).
- `tests/` — автотесты.
