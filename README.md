# Pixel Fighters — 2D-файтинг на Godot

## Как запустить
Скачать Godot (версия 4.7.2, портативная).
1. Запусти его.
2. В открывшемся окне выбери «Импорт» и укажи папку `PixelFighters` (файл `project.godot`).
3. Дождись, пока редактор импортирует PNG-ассеты (первый запуск занимает немного времени).
4. Запуск — клавиша F5 (или кнопка Play).

## Главное меню
- Выбери персонажа, кликнув по карточке (красная рамка = выбор).
- «Сложность бота»: Лёгкий / Средний / Сложный.
- «Режим»: Против бота (бот играет за случайного персонажа) или 2 игрока на одной клавиатуре.
- «УПРАВЛЕНИЕ» — настройка клавиш: выбери строку, нажми нужную клавишу; есть сброс по умолчанию, настройки сохраняются.
- Кнопка «НАЧАТЬ БОЙ».

## Управление
- **Игрок 1**: A/D — движение, W — прыжок, S — присед, J — быстрый удар, K — сильный удар, L — способность, Shift — рывок.
- **Игрок 2**: стрелки, 1 — быстрый удар, 2 — сильный, 3 — способность, Ctrl — рывок.
- Клавиши меняются в меню («УПРАВЛЕНИЕ»), Esc отменяет выбор.
- **Авто-блок**: если персонаж бездействует (не двигается, не атакует), он сам встаёт в защитную стойку — входящий урон режется до ~15%; при успешной защите показывается анимация блока.
- **Присед (S / Ctrl)**: низкая стойка — высокие удары (панч) пролетают над головой; в приседе нельзя ходить. Удар из приседа (J / 1) — подкат («скольжение»), бьёт по ногам.
- **Удары в воздухе**: любой удар (J/K, 1/2) в воздухе превращается в прыжковый удар (анимация прыжкового удара).
- **Прыжок**: стартует сразу (у TITAN отталкивание медленное — «тяжеловес»); в полёте — фиксированная поза, приземление — отдельная анимация.
- **Потеря равновесия**: сильный удар, полученный в прыжке, во время атаки или рывка, сбивает персонажа — он кувыркается, теряет управление, затем встаёт (анимация вставания).
- Комбо: быстрый → быстрый → сильный (отменяется при попадании).
- **Пауза во время боя: Esc** — меню: Продолжить (Esc), Начать раунд заново, Выйти в главное меню.
- После боя: Enter — в меню, R — заново, Esc — меню.

## Раунды
Best-of-3: кто победит 2 раунда — тот выиграл матч. Раунд длится 99 секунд; по таймеру побеждает тот, у кого больше HP. Победа нокаутом — K.O. с замедлением и тряской экрана.

## Персонажи
- **VEX (striker)** — быстрый, HP 100. Способность: усиленный удар с резким рывком вперёд (сильный урон).
- **TITAN (bruiser)** — тяжёлый, HP 140, медленный. Способность: землетрясение — прыжок и удар об землю с ударной волной по площади.
- **LUNA (acrobat)** — хрупкая (HP 80), очень быстрая, **двойной прыжок**, рывок с неуязвимостью. Способность: небесный клык — удар в воздухе.
- **MAGNA (mage)** — HP 90. Способность: огненный шар — снаряд, летит в противника (запуск только на земле).

У всех есть: удары (быстрый/сильный/воздушный/подкат из приседа), авто-блок при бездействии с анимацией успешной защиты, присед, прыжок, рывок, получение урона, потеря равновесия от сильных ударов с анимацией вставания и KO с анимацией падения (фигура падает и ложится, без зацикливания).

## Структура
- `scripts/CharData.gd` — данные персонажей (HP, скорость, удары, анимации).
- `scripts/Fighter.gd` — боевая логика бойца (состояния, хитбоксы).
- `scripts/Projectile.gd` — снаряд мага.
- `scripts/Fight.gd` — арена, HUD, раунды, ввод, ИИ бота.
- `scripts/MainMenu.gd` — меню.
- `assets/Anim/` — спрайт-листы (128×128 на кадр).
